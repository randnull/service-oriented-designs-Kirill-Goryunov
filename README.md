# Social Network

# Запуск

```
docker-compose up -d
```

# Описание сервисов

## Main Service (Python)

Сервис, предоставляющий API для клиента:

1. Регистрация
2. Аутентификация
3. Создание/редактирование/удаление/просмотр поста
4. Отправка лайка и просмотр на пост

## Post Service (Golang)

Сервис для создание, хранения и выдачи поста.

## Statistic Service (Python)

Сервис для приема нового события (лайк/просмотр), подсчета и выдачи статистики:

1. Топ популярных постов
2. Топ популярных пользователей
